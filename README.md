# 窗口互传 0.3.0 候选

适用于 DeepSeek Harness Web 0.2.2-rc.1。包名与右栏入口沿用 0.2.0。正式替换需按当前运行授权和验收办理。

1. 在 DSH 左侧通过「插件 → 添加插件」安装本目录并启用。
2. 打开会话右侧栏的「开始 → 窗口互传」。勾选两个独立会话并保存启用开关。设置作用于当前 Web 配置。
3. 每条新消息由 DSH 所有者在**发送会话**输入一条指令。首行写 `授权互传 目标会话ID 请求号`，从下一行开始写准确正文。
4. 助手在该轮调用 `send_session_message`，目标、请求号和正文须与指令完全一致。查询投递和处理用原发送会话的 `session_message_status`。

例如，目标 ID 为 `example-session` 的合成指令如下。

```text
授权互传 example-session report-01
请确认收到这条合成消息。
```

白名单限制可互传的会话。每条新消息另需当前轮次的所有者指令。工具检查 DSH Host 生成的原生 `user`、请求标识和指令内容。0.2.2-rc.1 省略所有者 principal，显式记录非所有者 principal。当前候选仅在该宿主版本受理新发送。收到中继的轮次不受理发送授权。普通用户文字、模型参数和中继正文无法生成授权。发送前再核对当前轮次、发送身份、启用状态和白名单。该约束覆盖本插件的工具入口，以 DSH 已认证所有者客户端和同进程可信插件为边界。

旧回执位置与去重键保持兼容。完全相同的已保留请求只返回原回执。相同请求号对应不同正文或目标时会被拒绝。授权随轮次结束失效，重启后不会恢复未用授权。投递、处理和实际业务完成分别判定。
